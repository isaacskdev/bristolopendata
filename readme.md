# Bristol Air Quality Explorer

The project will be a web-based application called Bristol Air Quality Explorer. It will use Bristol City Council's air-quality dataset to allow users to explore and understand air pollution across Bristol.

The application will retrieve data from the Bristol Open Data API using JavaScript and present it in an accessible, interactive dashboard. Users will be able to explore air-quality information, view monitoring locations, filter measurements and compare pollution levels between different areas.

# Dataset description
The dataset provides information about air pollution in Bristol, including annual mean nitrogen dioxide (NO₂) measurements. This information can be used to explore differences in pollution levels across locations in the city.

# Dataset link: [Bristol Open Data – Air Quality Explorer](https://opendata.bristol.gov.uk/apps/bcf5a6312bc04ffeb43db67cd57f5439/explore)

# Main aim
The aim of the project is to make Bristol's air-quality information easier to access and understand by presenting the data through an interactive website, allowing users to identify pollution patterns and compare different areas of Bristol.
